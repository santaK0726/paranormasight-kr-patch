PARANORMASIGHT 1 한국어 패치 v0.1 (2026-10-25)

대상: Steam Windows판 PARANORMASIGHT: The Seven Mysteries of Honjo
지원 게임 build: 20284335 (설치 시 원본 파일 SHA-256을 자동 확인)
일본어 원문을 기준으로 번역했으며 English 언어 슬롯에 적용합니다.

[설치]
1. Steam에서 게임을 설치하고 게임을 종료합니다.
2. PARANORMASIGHT_KR_Setup.exe를 실행합니다.
3. 자동으로 찾은 게임 폴더를 확인하거나 [폴더 선택]을 누릅니다.
   Steam → 게임 우클릭 → 관리 → 로컬 파일 탐색에서 열리는 폴더입니다.
   PARANORMASIGHT.exe와 PARANORMASIGHT_Data가 함께 있는 폴더를 선택하세요.
4. [한글패치 설치]를 누르고 완료될 때까지 기다립니다.
5. Steam으로 평소처럼 게임을 실행하고 설정 → 언어 → 한국어를 선택합니다.
   언어명이 English로 표시되는 화면이라면 English를 선택하세요.

설치 EXE 하나에 패치 데이터가 모두 포함됩니다. 인터넷/Python/별도 압축 도구는
필요하지 않습니다. EXE를 스팀 게임 폴더에 복사해 실행해도 됩니다.
이 패치는 파일을 직접 덮어쓰는 복사본이 아닌, 설치된 원본이 필요한 차분 패치입니다.
게임 원본 EXE/전체 게임 데이터/추출 대사/개인 세이브는 들어 있지 않습니다.
Windows 10/11 64비트(.NET Framework 4.8 및 Windows PowerShell 기본 구성)가 대상입니다.
원본 백업과 재구성 데이터용으로 시스템 드라이브에 약 2GB의 여유 공간을 확보하세요.

[원상복구]
같은 설치 EXE를 실행하고 같은 게임 폴더를 선택한 뒤 [원본으로 복구]를 누릅니다.
원본 백업은 %LOCALAPPDATA%\PARANORMASIGHT_KR_Patch 아래에 보관됩니다.
복구하기 전까지 이 폴더를 지우지 마세요. 사용자 세이브와 게임 설정은 변경하지 않습니다.
원본 파일이 이미 다른 패치나 Steam 업데이트로 바뀌었다면 덮어쓰기를 중단합니다.
게임 업데이트/다른 패치 적용 전에는 먼저 원상복구하세요. 문제가 생기면 Steam의
설치된 파일 → 게임 파일 무결성 검사를 이용할 수 있습니다. 이때 패치 helper DLL은
Steam에서 관리하지 않으므로 가능하면 설치 EXE의 원상복구를 먼저 이용하세요.

[수록]
선택된 한국어 텍스트 13,388건, 우선 이미지 9개, 코쿠리판,
일반 대사/UI 글꼴, 명조 연출·크레딧, 붓글씨 엔딩, 한글 이름 입력을 포함합니다.
읽기 어려운 원화 두 곳과 원문상 판독할 수 없는 병 라벨은 원형을 유지했습니다.
최신 수정본010에 대응합니다. 번역·폰트·크기 수정이 반영된 배포용 설치 패키지이며,
게임 전체 구간의 플레이 검증은 미완료입니다. 검증 완료판으로 표시하지 않습니다.

[실패 시]
설치 창에 표시되는 install.log/restore.log 위치를 확인하세요.
지원 원본이 일치하지 않거나 게임이 실행 중이면 덮어쓰지 않습니다.
이미 설치된 경우 먼저 복구한 다음 재설치하세요.

[고지]
비공식 팬 번역 패치이며 원작/상표/원화의 권리는 각 권리자에게 있습니다.
폰트의 출처·수정명·SIL OFL 1.1 라이선스는 동봉 LICENSES 및 설치 데이터에 있습니다.
설치 EXE는 디지털 서명되지 않았습니다. 이 패키지는 외부에 자동 게시하지 않습니다.
