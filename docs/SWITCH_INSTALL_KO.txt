PARANORMASIGHT 1 한국어 패치 v0.1.3-Switch.1 (2026-10-26)

대상: Nintendo Switch 본편01006E5019C5A000 + 업데이트1.2(131072)
일본어 원문 기반 / English 언어 슬롯에 적용 / PCv0.1.3 번역·폰트·이미지 반영

공개용은 원본1.2 RomFS가 필요한 차분 생성기입니다.
Windows10/11 x64, 기본 .NET Framework4.8로 실행하며 Python/인터넷/키 파일이 필요 없습니다.
NSP/NCA·원본 게임 실행 코드·완전한 게임 자산·추출 원문·세이브는 동봉하지 않습니다.

1. 본인 게임의 업데이트1.2가 합쳐진 원본 RomFS를 준비합니다.
   Eden 사용자는 게임 속성에서 Update1.2를 활성화하고 게임 우클릭 → Dump RomFS로
   전체 RomFS를 덤프할 수 있습니다. 한글 모드는 덤프 전에 비활성화하세요.
   이미 덤프한 원본1.2의 Data 폴더가 있으면 그대로 사용합니다.
2. PARANORMASIGHT_KR_Switch_Generator.exe를 실행합니다.
3. 원본 폴더에서 RomFS의 Data 또는 Data를 포함한 상위 폴더를 선택합니다.
4. 새 출력 위치를 정하고 환경을 선택한 뒤 [한글 모드 생성]을 누릅니다.
   지원 원본8개 해시를 확인하여 시험본과 동일한 모드 파일을 생성합니다.
   다른 버전/한글 적용 파일이면 중단합니다. 원본 폴더는 변경하지 않습니다.

[Eden]
게임 우클릭 → Open Mod Data Location에 생성된 Eden/PARANORMASIGHT_KR_Switch_test001
폴더를 통째로 복사합니다. 열린 제목ID 폴더 바로 아래에 romfs/exefs를 풀지 마세요.
정확한 구조: 제목ID/PARANORMASIGHT_KR_Switch_test001/romfs/Data/...
게임 속성에서 한글 모드와 Update1.2를 각각 활성화합니다.
언어는 한국어(English 슬롯)를 선택합니다.

[실기 Atmosphère]
생성된 Atmosphere/atmosphere 폴더를 SD 카드 최상위에 복사합니다.
/atmosphere/contents/01006E5019C5A000/romfs/Data/...
/atmosphere/exefs_patches/PARANORMASIGHT_KR_Switch_test001/*.ips
같은 게임의 다른 번역 모드는 따로 보관하여 중복 적용을 피하세요.

[제거]
Eden에서는 이 모드를 비활성화하거나 해당 모드 폴더만 제거합니다.
실기는 이 패치의 romfs/Data8파일과 전용 exefs_patches 폴더만 제거합니다.
게임/SD 전체 atmosphere 폴더나 개인 세이브를 지우지 마세요.

전 구간 완주/사람의 전체 문장 검수 완료를 의미하지 않습니다.
