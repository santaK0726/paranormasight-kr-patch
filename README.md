## 설치

1. Steam에서 게임을 설치하고 종료합니다.
2. 다운로드한 ZIP의 압축을 풀고 `PARANORMASIGHT_KR_Setup.exe`를 실행합니다.
3. 게임 폴더를 선택하고 **한글패치 설치**를 누릅니다.
4. Steam으로 게임을 실행해 설정의 언어를 **한국어**로 선택합니다. English로 표시되는 화면에서는 English를 선택합니다.

지원 원본은 Steam Windows **build 20284335**입니다. 설치 프로그램이 정확한 파일 SHA-256을 확인하며, 다른 원본이나 이미 적용된 파일을 임의로 덮어쓰지 않습니다.
시스템 드라이브에 원본 백업·재구성용 여유 공간 약 2GB가 필요합니다.

## 원상복구

같은 설치 EXE에서 같은 게임 폴더를 선택한 뒤 **원본으로 복구**를 누르세요.
원본 백업은 `%LOCALAPPDATA%\PARANORMASIGHT_KR_Patch`에 보관됩니다. 복구 전까지 삭제하지 마세요.
설치 프로그램은 사용자 세이브나 게임 설정을 직접 변경하지 않습니다.
